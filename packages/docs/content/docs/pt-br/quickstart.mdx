# Início rápido

Instale OpenCode e Node.js 24.14 ou posterior no servidor. Instale e autentique Claude Code ou Codex se quiser usá-los. Depois instale Multichamber com o comando abaixo.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Abra a URL exibida, normalmente `http://localhost:3000`. Escolha um motor disponível para uma nova sessão. As configurações mantêm padrões de modelo e permissões separados por motor.

Use uma senha forte na interface antes de permitir acesso remoto.

Use o aplicativo desktop no macOS, Windows ou Linux, ou execute o servidor web/PWA. As versões iOS e Android se conectam a um servidor existente. Este fork não fornece uma extensão do VS Code.
