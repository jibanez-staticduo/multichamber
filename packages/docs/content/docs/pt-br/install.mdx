# Instalação

## Escolha o aplicativo

Use o aplicativo desktop no macOS, Windows ou Linux, ou execute o servidor web/PWA. As versões iOS e Android se conectam a um servidor existente. Este fork não fornece uma extensão do VS Code.

O desktop inclui OpenCode. O servidor web precisa de OpenCode e Node.js 24.14 ou posterior. Para Claude Code ou Codex, instale e autentique cada CLI nativa no servidor; OpenCode não as inclui.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Use apenas arquivos ou links de distribuição publicados para este fork. iOS precisa de assinatura e distribuição autorizada pelo TestFlight ou App Store; não há promessa de beta público. Android precisa de um APK assinado compatível. A web móvel funciona sem uma compilação nativa.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix gerencia atualizações dos aplicativos em seu armazenamento. Recompile com o flake atualizado; o atualizador do OpenCode não pode alterar o armazenamento Nix.
