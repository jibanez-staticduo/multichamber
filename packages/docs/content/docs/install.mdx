# Install

## Choose your app

Use the desktop app on macOS, Windows or Linux, or run the web/PWA server. iOS and Android builds connect to an existing server. This fork does not ship a VS Code extension.

Desktop bundles OpenCode. Web/server needs OpenCode and Node.js 24.14 or newer. To use Claude Code or Codex, install and authenticate each native CLI on the server host; they are not supplied by bundled OpenCode.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Use only mobile artifacts or distribution links published for this fork. iOS needs signing and an authorized TestFlight or App Store distribution; no public beta is promised. Android needs a matching signed APK. You can use the hosted mobile web interface without a native build.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix owns updates for store-installed applications. Rebuild from the updated flake; the packaged OpenCode updater cannot modify a Nix store path.
