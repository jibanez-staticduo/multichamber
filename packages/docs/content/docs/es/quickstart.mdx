# Inicio rápido

Instala OpenCode y Node.js 24.14 o posterior en el servidor. Instala y autentica allí Claude Code o Codex si quieres usarlos. Después instala Multichamber con el siguiente comando.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Abre la URL indicada, normalmente `http://localhost:3000`. Elige un motor disponible para una sesión nueva. Ajustes mantiene valores de modelo y permisos separados por motor.

Usa una contraseña de interfaz segura antes de permitir acceso remoto.

Usa la aplicación de escritorio en macOS, Windows o Linux, o ejecuta el servidor web/PWA. Las compilaciones de iOS y Android se conectan a un servidor existente. Este fork no incluye una extensión de VS Code.
