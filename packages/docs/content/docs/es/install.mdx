# Instalar

## Elige tu aplicación

Usa la aplicación de escritorio en macOS, Windows o Linux, o ejecuta el servidor web/PWA. Las compilaciones de iOS y Android se conectan a un servidor existente. Este fork no incluye una extensión de VS Code.

Escritorio incluye OpenCode. El servidor web necesita OpenCode y Node.js 24.14 o posterior. Para usar Claude Code o Codex, instala y autentica cada CLI nativa en el servidor; OpenCode no las incluye.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Usa solo los archivos o enlaces de distribución publicados para este fork. iOS necesita firma y distribución autorizada mediante TestFlight o App Store; no se promete una beta pública. Android necesita un APK firmado compatible. Puedes usar la web móvil sin una compilación nativa.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix gestiona las actualizaciones de las aplicaciones instaladas en su almacén. Reconstruye con el flake actualizado; el actualizador de OpenCode no puede modificar una ruta del almacén Nix.
