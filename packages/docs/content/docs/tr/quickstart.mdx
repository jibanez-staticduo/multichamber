# Hızlı başlangıç

Sunucuya OpenCode ve Node.js 24.14 veya yenisini kurun. Kullanacaksanız Claude Code veya Codex’i aynı sunucuya kurup kimlik doğrulayın. Ardından aşağıdaki komutla Multichamber’ı kurun.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Yazdırılan adresi açın; genellikle `http://localhost:3000` olur. Yeni oturum için kullanılabilir motoru seçin. Ayarlar her motorun model ve izin varsayılanlarını ayrı saklar.

Uzaktan erişime izin vermeden önce güçlü bir arayüz parolası kullanın.

macOS, Windows veya Linux masaüstü uygulamasını kullanın ya da web/PWA sunucusunu çalıştırın. iOS ve Android derlemeleri mevcut bir sunucuya bağlanır. Bu çatallanma VS Code uzantısı sunmaz.
