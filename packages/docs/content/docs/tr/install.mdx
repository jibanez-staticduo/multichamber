# Kurulum

## Uygulamanızı seçin

macOS, Windows veya Linux masaüstü uygulamasını kullanın ya da web/PWA sunucusunu çalıştırın. iOS ve Android derlemeleri mevcut bir sunucuya bağlanır. Bu çatallanma VS Code uzantısı sunmaz.

Masaüstü OpenCode içerir. Web sunucusu OpenCode ve Node.js 24.14 veya yenisini gerektirir. Claude Code veya Codex için her yerel CLI aracını sunucuya kurup kimlik doğrulayın; bunlar OpenCode ile gelmez.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Yalnızca bu çatallanma için yayımlanan dosya veya dağıtım bağlantılarını kullanın. iOS imzalama ve yetkili TestFlight veya App Store dağıtımı gerektirir; herkese açık beta sözü verilmez. Android uyumlu imzalı APK gerektirir. Yerel derleme olmadan mobil web kullanılabilir.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix deposundaki uygulamaların güncellemelerini Nix yönetir. Güncel flake ile yeniden derleyin; OpenCode güncelleyicisi Nix deposunu değiştiremez.
