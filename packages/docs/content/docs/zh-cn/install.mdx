# 安装

## 选择应用

使用 macOS、Windows 或 Linux 桌面应用，或运行网页/PWA 服务器。iOS 和 Android 构建连接到现有服务器。本分支不提供 VS Code 扩展。

桌面应用自带 OpenCode。网页服务器需要 OpenCode 和 Node.js 24.14 或更新版本。要使用 Claude Code 或 Codex，请在服务器上分别安装并登录其原生 CLI；OpenCode 不包含这些程序。

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

仅使用为本分支发布的文件或分发链接。iOS 需要签名和授权的 TestFlight 或 App Store 分发，不承诺公开测试版。Android 需要兼容的签名 APK。无需原生构建也可使用手机网页。

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix 管理其存储中的应用更新。请使用更新后的 flake 重新构建；OpenCode 更新程序无法修改 Nix 存储路径。
