# 快速开始

在服务器上安装 OpenCode 和 Node.js 24.14 或更新版本。如需 Claude Code 或 Codex，请在该服务器上安装并登录。然后使用以下命令安装 Multichamber。

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

打开显示的地址，通常为 `http://localhost:3000`。为新会话选择可用引擎。设置会分别保存各引擎的模型和权限默认值。

允许远程访问前，请设置强 UI 密码。

使用 macOS、Windows 或 Linux 桌面应用，或运行网页/PWA 服务器。iOS 和 Android 构建连接到现有服务器。本分支不提供 VS Code 扩展。
