# Швидкий старт

Встановіть OpenCode та Node.js 24.14 або новіший на сервері. Встановіть і автентифікуйте там Claude Code або Codex, якщо хочете їх використовувати. Потім встановіть Multichamber наведеною командою.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Відкрийте показану адресу, зазвичай `http://localhost:3000`. Виберіть доступний рушій для нового сеансу. Налаштування зберігають окремі моделі й дозволи для кожного рушія.

Використовуйте надійний пароль інтерфейсу перед дозволом віддаленого доступу.

Використовуйте застосунок для macOS, Windows чи Linux або запустіть вебсервер/PWA. Збірки iOS та Android підключаються до наявного сервера. Цей форк не містить розширення VS Code.
