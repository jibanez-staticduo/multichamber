# Встановлення

## Виберіть застосунок

Використовуйте застосунок для macOS, Windows чи Linux або запустіть вебсервер/PWA. Збірки iOS та Android підключаються до наявного сервера. Цей форк не містить розширення VS Code.

Настільний застосунок містить OpenCode. Вебсервер потребує OpenCode та Node.js 24.14 або новішого. Для Claude Code або Codex встановіть і автентифікуйте кожну нативну CLI на сервері; OpenCode їх не постачає.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Використовуйте лише файли або посилання розповсюдження, опубліковані для цього форка. iOS потребує підпису та авторизованого розповсюдження через TestFlight або App Store; публічна бета не обіцяється. Android потребує сумісного підписаного APK. Мобільний веб працює без нативної збірки.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix керує оновленнями застосунків у своєму сховищі. Перебудуйте з оновленим flake; оновлювач OpenCode не може змінювати сховище Nix.
