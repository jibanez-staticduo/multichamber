# 설치

## 앱 선택

macOS, Windows, Linux 데스크톱 앱이나 웹/PWA 서버를 사용하세요. iOS와 Android 빌드는 기존 서버에 연결합니다. 이 포크는 VS Code 확장을 제공하지 않습니다.

데스크톱에는 OpenCode가 포함됩니다. 웹 서버에는 OpenCode와 Node.js 24.14 이상이 필요합니다. Claude Code나 Codex를 사용하려면 각 네이티브 CLI를 서버에 설치하고 인증하세요. OpenCode에는 포함되지 않습니다.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

이 포크용으로 게시된 파일이나 배포 링크만 사용하세요. iOS에는 서명과 승인된 TestFlight 또는 App Store 배포가 필요하며 공개 베타를 약속하지 않습니다. Android에는 호환되는 서명된 APK가 필요합니다. 네이티브 빌드 없이 모바일 웹을 사용할 수 있습니다.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix 저장소의 앱은 Nix가 업데이트합니다. 업데이트된 flake로 다시 빌드하세요. OpenCode 업데이트 기능은 Nix 저장소를 수정할 수 없습니다.
