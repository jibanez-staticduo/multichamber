# Instalacja

## Wybierz aplikację

Użyj aplikacji na macOS, Windows lub Linux albo uruchom serwer web/PWA. Kompilacje iOS i Android łączą się z istniejącym serwerem. Ten fork nie udostępnia rozszerzenia VS Code.

Aplikacja desktopowa zawiera OpenCode. Serwer web wymaga OpenCode i Node.js 24.14 lub nowszego. Aby używać Claude Code lub Codex, zainstaluj i uwierzytelnij ich natywne CLI na serwerze; OpenCode ich nie zawiera.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Używaj tylko plików lub odnośników dystrybucji opublikowanych dla tego forka. iOS wymaga podpisania i autoryzowanej dystrybucji TestFlight lub App Store; publiczna beta nie jest obiecana. Android wymaga zgodnego podpisanego APK. Mobilna strona działa bez natywnej kompilacji.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix zarządza aktualizacjami aplikacji w swoim magazynie. Przebuduj z aktualnym flake; aktualizator OpenCode nie może modyfikować magazynu Nix.
