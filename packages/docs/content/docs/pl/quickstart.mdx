# Szybki start

Zainstaluj OpenCode i Node.js 24.14 lub nowszy na serwerze. Zainstaluj i uwierzytelnij tam Claude Code lub Codex, jeśli chcesz ich używać. Następnie zainstaluj Multichamber poniższym poleceniem.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Otwórz podany adres, zwykle `http://localhost:3000`. Wybierz dostępny silnik dla nowej sesji. Ustawienia zachowują oddzielne modele i uprawnienia dla każdego silnika.

Użyj silnego hasła interfejsu przed włączeniem dostępu zdalnego.

Użyj aplikacji na macOS, Windows lub Linux albo uruchom serwer web/PWA. Kompilacje iOS i Android łączą się z istniejącym serwerem. Ten fork nie udostępnia rozszerzenia VS Code.
