# Installation

## App auswählen

Nutzen Sie die Desktop-App auf macOS, Windows oder Linux oder starten Sie den Web/PWA-Server. iOS- und Android-Builds verbinden sich mit einem bestehenden Server. Dieser Fork enthält keine VS-Code-Erweiterung.

Desktop enthält OpenCode. Der Webserver benötigt OpenCode und Node.js 24.14 oder neuer. Für Claude Code oder Codex installieren und authentifizieren Sie die jeweilige native CLI auf dem Server; OpenCode liefert sie nicht mit.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Verwenden Sie nur für diesen Fork veröffentlichte Dateien oder Vertriebslinks. iOS benötigt Signierung und autorisierten TestFlight- oder App-Store-Vertrieb; eine öffentliche Beta wird nicht zugesagt. Android benötigt ein passend signiertes APK. Das mobile Web funktioniert ohne nativen Build.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix verwaltet Updates seiner installierten Anwendungen. Bauen Sie mit dem aktualisierten Flake neu; der OpenCode-Updater kann den Nix-Store nicht verändern.
