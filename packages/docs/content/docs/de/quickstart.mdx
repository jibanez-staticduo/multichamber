# Schnellstart

Installieren Sie OpenCode und Node.js 24.14 oder neuer auf dem Server. Installieren und authentifizieren Sie dort bei Bedarf Claude Code oder Codex. Installieren Sie anschließend Multichamber mit dem folgenden Befehl.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Öffnen Sie die angezeigte URL, gewöhnlich `http://localhost:3000`. Wählen Sie eine verfügbare Engine für eine neue Sitzung. Die Einstellungen behalten getrennte Modell- und Berechtigungsvorgaben pro Engine.

Verwenden Sie vor dem Fernzugriff ein starkes UI-Passwort.

Nutzen Sie die Desktop-App auf macOS, Windows oder Linux oder starten Sie den Web/PWA-Server. iOS- und Android-Builds verbinden sich mit einem bestehenden Server. Dieser Fork enthält keine VS-Code-Erweiterung.
