# クイックスタート

サーバーにOpenCodeとNode.js 24.14以降をインストールします。Claude CodeやCodexを使う場合は、同じサーバーでインストールと認証を行います。その後、次のコマンドでMultichamberをインストールします。

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

表示されたURL（通常は`http://localhost:3000`）を開きます。新しいセッションの利用可能なエンジンを選びます。設定ではエンジンごとにモデルと権限の既定値を保存できます。

リモートアクセスを許可する前に強力なUIパスワードを設定してください。

macOS、Windows、Linuxのデスクトップアプリ、またはウェブ/PWAサーバーを使えます。iOSとAndroidのビルドは既存のサーバーに接続します。このフォークはVS Code拡張を提供しません。
