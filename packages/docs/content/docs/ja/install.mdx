# インストール

## アプリを選ぶ

macOS、Windows、Linuxのデスクトップアプリ、またはウェブ/PWAサーバーを使えます。iOSとAndroidのビルドは既存のサーバーに接続します。このフォークはVS Code拡張を提供しません。

デスクトップにはOpenCodeが含まれます。ウェブサーバーにはOpenCodeとNode.js 24.14以降が必要です。Claude CodeやCodexを使う場合は、それぞれのネイティブCLIをサーバーにインストールして認証してください。OpenCodeには含まれません。

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

このフォーク向けに公開されたファイルや配布リンクだけを使ってください。iOSには署名と承認されたTestFlightまたはApp Store配布が必要です。公開ベータは約束されていません。Androidには対応する署名済みAPKが必要です。ネイティブビルドなしでもモバイルウェブを使えます。

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

NixストアのアプリはNixで更新します。更新したflakeから再ビルドしてください。OpenCodeの更新機能はNixストアを変更できません。
