# Quickstart

Install OpenCode and Node.js 24.14 or newer on the server. Install and authenticate Claude Code or Codex there if you want to use them. Then install Multichamber using the command below.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Open the printed URL, usually `http://localhost:3000`. Choose an available engine for a new session. Settings keep separate model and permission defaults for each engine.

Use a strong UI password before allowing remote access.

Use the desktop app on macOS, Windows or Linux, or run the web/PWA server. iOS and Android builds connect to an existing server. This fork does not ship a VS Code extension.
