# Démarrage rapide

Installez OpenCode et Node.js 24.14 ou ultérieur sur le serveur. Installez et authentifiez Claude Code ou Codex si vous souhaitez les utiliser. Installez ensuite Multichamber avec la commande suivante.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Ouvrez l’URL affichée, généralement `http://localhost:3000`. Choisissez un moteur disponible pour une nouvelle session. Les réglages conservent des modèles et permissions distincts par moteur.

Utilisez un mot de passe d’interface fort avant d’autoriser l’accès distant.

Utilisez l’application de bureau sur macOS, Windows ou Linux, ou lancez le serveur web/PWA. Les versions iOS et Android se connectent à un serveur existant. Ce fork ne fournit pas d’extension VS Code.
