# Installation

## Choisir une application

Utilisez l’application de bureau sur macOS, Windows ou Linux, ou lancez le serveur web/PWA. Les versions iOS et Android se connectent à un serveur existant. Ce fork ne fournit pas d’extension VS Code.

L’application de bureau inclut OpenCode. Le serveur web nécessite OpenCode et Node.js 24.14 ou ultérieur. Pour Claude Code ou Codex, installez et authentifiez chaque CLI native sur le serveur ; OpenCode ne les fournit pas.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Utilisez uniquement les fichiers ou liens de distribution publiés pour ce fork. iOS nécessite une signature et une distribution TestFlight ou App Store autorisée ; aucune bêta publique n’est promise. Android nécessite un APK signé compatible. Le web mobile reste utilisable sans application native.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix gère les mises à jour des applications de son magasin. Reconstruisez avec le flake mis à jour ; le programme de mise à jour OpenCode ne peut pas modifier le magasin Nix.
