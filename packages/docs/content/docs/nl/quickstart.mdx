# Snelstart

Installeer OpenCode en Node.js 24.14 of nieuwer op de server. Installeer en authenticeer daar Claude Code of Codex als je die wilt gebruiken. Installeer daarna Multichamber met de volgende opdracht.

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

Open de getoonde URL, meestal `http://localhost:3000`. Kies een beschikbare engine voor een nieuwe sessie. Instellingen bewaren aparte modellen en machtigingen per engine.

Gebruik een sterk UI-wachtwoord voordat je externe toegang toestaat.

Gebruik de desktopapp op macOS, Windows of Linux, of start de web/PWA-server. iOS- en Android-builds verbinden met een bestaande server. Deze fork bevat geen VS Code-extensie.
