# Installeren

## Kies je app

Gebruik de desktopapp op macOS, Windows of Linux, of start de web/PWA-server. iOS- en Android-builds verbinden met een bestaande server. Deze fork bevat geen VS Code-extensie.

Desktop bevat OpenCode. De webserver vereist OpenCode en Node.js 24.14 of nieuwer. Installeer en authenticeer voor Claude Code of Codex elke native CLI op de server; OpenCode levert deze niet mee.

[Multichamber](https://github.com/jibanez-staticduo/multichamber/releases)

## Web / PWA

```bash
curl -fsSL https://raw.githubusercontent.com/jibanez-staticduo/multichamber/main/scripts/install.sh | bash
multichamber --ui-password be-creative-here
```

## iOS / Android

Gebruik alleen bestanden of distributielinks die voor deze fork zijn gepubliceerd. iOS vereist ondertekening en bevoegde TestFlight- of App Store-distributie; een publieke bèta wordt niet beloofd. Android vereist een passend ondertekend APK. Mobiel web werkt zonder native build.

## Nix

```bash
nix run github:jibanez-staticduo/multichamber
nix run github:jibanez-staticduo/multichamber#gui
```

`packages.multichamber` · `packages.multichamber-desktop` · `nixosModules.multichamber`

Nix beheert updates van toepassingen in zijn store. Bouw opnieuw met de bijgewerkte flake; de OpenCode-updater kan de Nix-store niet wijzigen.
